Go2Fetch

LiDAR–Camera Sensor Fusion for Real-Time Mapping, Object Detection, and Autonomous Navigation on a Unitree Go2

Siri Kelshikar

Paper coming soon Code Demo coming soon

Overview

This project presents an autonomous indoor navigation system for a Unitree Go2 quadruped robot equipped with LiDAR and a camera. The robot combines its built-in odometry with LiDAR measurements to construct a two-dimensional occupancy grid in real time.

A graph-based path-planning algorithm is then applied to the generated map to compute a collision-free route toward a target location. The planned path is converted into a sequence of motion and yaw commands that guide the robot through the environment.

Objects of interest are detected using YOLO. When a target object, such as a chair, is identified, LiDAR points are projected into the camera frame to estimate the object’s distance and position relative to the robot. The robot then updates its navigation goal and autonomously approaches the detected object.

The system demonstrates real-time mapping, object detection, sensor fusion, path planning, and autonomous object fetching in indoor environments.

System Pipeline

01

Real-Time Mapping

Fuse LiDAR measurements with built-in odometry to create a 2D occupancy grid.

02

Object Detection

Use YOLO and the onboard camera to detect a target object such as a chair.

03

Sensor Fusion

Project LiDAR points into the camera frame to estimate target distance and position.

04

Path Planning

Compute a collision-free route through the generated occupancy grid.

05

Robot Control

Convert the planned path into queued motion and yaw commands.

06

Object Fetching

Navigate toward and autonomously approach the detected object.
